# AI 1º Project - Santa's Workshop Tour

## How to run the code

First lets create a venv in order to manage the requirements without braking the system packages

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Then we execute the main


```bash
python3 main.py
```

Then in a browser we open a the link `http://127.0.0.1:8080`
